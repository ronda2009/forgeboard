# tools 索引

| 脚本 | 用途 |
|---|---|
| `anchors-probe.cjs` | 核对前端补丁锚点是否唯一 |
| `bump-version.cjs` | 改版本号（`internal/cli/cli.go`，唯一出处） |
| `dump-task-query.cjs` | 导出开机计划任务的查询语句 |
| `en-formal.cjs` | 英文文案正式度复核（缩写、口语词、冠词） |
| `en-sweep.cjs` | 扫英文文案里混入的中文字符 |
| `extract-manifest.cjs` | 从 `.syso` 里取出 Windows 清单 |
| `fetch-llama-swap.cjs` | 下载 llama-swap 供 `go:embed` |
| `find-js-error.cjs` | 二分定位 JS 语法错误所在行 |
| `fix-icon-id.cjs` | 改 `.syso` 里组图标的资源编号 |
| `frontend-render-check.cjs` | 喂真实数据跑渲染函数，核对界面输出 |
| `frontend-wiring-check.cjs` | 前端接线自检（元素 id、事件、按钮） |
| `i18n-check.cjs` | 中英词典键数与占位符核对 |
| `i18n-orphan-scan.cjs` | 找词典里没人用的键 |
| `parse-rsrc.cjs` | 读 exe 资源里的图标编号 |
| `pe-subsystem.cjs` | 判 PE 子系统（2＝GUI 无黑框，3＝控制台） |
| `set-lang.cjs` | 切换界面语言 |
| `selftest-run.ps1` | 起界面跑自检并读回日志 |
| `scroll-shot.ps1` | 长表格下半部分截图 |
| `wheel-shot.ps1` | 滚轮滚动后截图 |
| `swap-realtest.ps1` | 换模型器真跑一轮 |
| `icon-candidates/` | 图标候选 |
